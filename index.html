Security

This IDE runs Python entirely in your browser via Pyodide (WebAssembly) — no code is ever sent to a server, so classic remote-execution risks (server filesystem/credential access, etc.) don't apply here. Execution is isolated in a Web Worker, so an infinite loop or crash can be stopped without freezing the page, and each Worker gets a fresh Pyodide heap after Stop/Restart. If you ever move Python execution to a server for a multi-user product, don't call exec(user_code) directly — run it in an isolated, non-root container with CPU/memory limits, an execution timeout, restricted filesystem and network access, process limits, a package allow-list, and cleanup after every run.
